## 🎓 LAS 6 DIMENSIONES DE ANÁLISIS

### 1️⃣ **Neutralidad del Lenguaje** (0-100)
```
Mide: Palabras emotivas, intensificadores, adjetivos tendenciosos
Bajo (0-30):   Muy neutral ✅
Medio (30-70): Equilibrado
Alto (70-100): Muy emotivo 🚩
```

### 2️⃣ **Calidad de Fuentes** (0-100)
```
Mide: Citas directas, atribuciones, tipos de fuentes
Bajo (0-30):   Pocas fuentes 🚩
Medio (30-70): Fuentes moderadas
Alto (70-100): Excelentes fuentes ✅
```

### 3️⃣ **Balance de Perspectivas** (0-100)
```
Mide: ¿Presenta múltiples puntos de vista?, ¿Menciona críticas?
Bajo (0-30):   Solo una perspectiva 🚩
Medio (30-70): Mayormente equilibrado
Alto (70-100): Muy equilibrado ✅
```

### 4️⃣ **Énfasis Adecuado** (0-100)
```
Mide: Información principal en título, contexto, colocación
Bajo (0-30):   Énfasis problemático 🚩
Medio (30-70): Énfasis aceptable
Alto (70-100): Énfasis equilibrado ✅
```

### 5️⃣ **Detección de Patrones Sesgados**
```
Personalización negativa
Generalización de grupos
Victimización
Dehumanización
```

### 6️⃣ **Score de Sesgo Total** (0-100)
```
Combinación ponderada de todas las métricas:
- Neutralidad: 30%
- Atribución: 20%
- Balance: 30%
- Énfasis: 20%
```
